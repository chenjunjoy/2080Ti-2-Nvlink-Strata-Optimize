Let $y$ be the cost of the bat.

   $$y = x + 1.00$$

$$x + (x + 1.00) = 1.10$$
$$2x + 1.00 = 1.10$$
$$2x = 0.10$$
$$x = 0.05$$

def solve(nums):
    if not nums:
        return 0
    tails = []
    for num in nums:
        lo, hi = 0, len(tails)
        while lo < hi:
            mid = (lo + hi) // 2
            if tails[mid] < num:
                lo = mid + 1
            else:
                hi = mid
        if lo == len(tails):
            tails.append(num)
        else:
            tails[lo] = num
    return len(tails)
```

Let $c$ be the number of chickens.
Let $r$ be the number of rabbits.

**2. Set up Equations:**
*   **Heads:** Each animal has 1 head.
    $$c + r = 35$$
*   **Legs:** Chickens have 2 legs, and rabbits have 4 legs.
    $$2c + 4r = 94$$

**3. Solve the System:**

From the first equation, express $c$ in terms of $r$:
$$c = 35 - r$$

Substitute this into the second equation:
$$2(35 - r) + 4r = 94$$

Expand and simplify:
$$70 - 2r + 4r = 94$$
$$70 + 2r = 94$$

Subtract 70 from both sides:
$$2r = 24$$

Divide by 2:
$$r = 12$$

Now, find the number of chickens ($c$):
$$c = 35 - 12$$
$$c = 23$$

**4. Verification:**
*   **Heads:** $23 + 12 = 35$ (Correct)
*   **Legs:** $(23 \times 2) + (12 \times 4) = 46 + 48 = 94$ (Correct)

def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```
